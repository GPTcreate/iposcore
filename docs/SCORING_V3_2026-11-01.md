# 감성 분류·배점 v3

사용자가 2026-11-01 과거 오류 정정과 배점 구현을 요청하며 약간 낙관적인 기준을 허용했다. 아래 값은 그 방향에 따라 선택한 운영 기준이다. 과거 7종목의 성과로 최적화하거나 예측력을 입증한 값이 아니다.

## 적용 규칙

- 청약 D-2 이전: 정량 원점수 Q(경쟁률 40·확약 25·유통 20, 최대 85)를 100점으로 환산한다.
- KST 청약 D-1 00시부터: 필수 정량 3지표와 유효한 독립 의견이 있으면 종합점수를 계산한다.
- 참여·유보·불참의 감성지수 값을 각각 **100·65·15**로 둔다. 유보를 불참과 구별하고 조금 우호적으로 해석한다. 이는 글쓴이의 청약 의사를 비교하는 값이며 회사 가치나 수익 확률이 아니다.
- 독립 표본 수 n이 1~5일 때 감성 비중을 5·10·15·20·25%로 높인다. 5건 이상은 25%다. 한 글에 모든 비중을 주지 않는다.
- 무표본·미분류에는 감성지수를 만들지 않는다. 정량 미완성은 발표 대기, 무표본은 정량 유지다. 일정 충돌·철회·미정의 감성 차단도 유지한다.
- 현재의 관측 참여/유보/불참 비율은 그대로 공개하고, 감성지수와 섞지 않는다. 최신 블로그·작성자 1표, 실패 채널 제외 원칙도 유지한다.

```
T = Q / 85 * 100
I = (100 * 참여 + 65 * 유보 + 15 * 불참) / n
W = 25 * min(1, n / 5)
종합 = round(T * (1 - W / 100) + I * W / 100)
```

정량값을 먼저 정수로 반올림하지 않는다. 마지막 합계에서 한 번 반올림한다. `sentimentConfidence`는 n/5의 표본 충족률이며 투자 성과의 신뢰확률이 아니다. API는 `scoreVersion=2026-11-01-v3`, 감성지수·비중·표본 충족률을 제공한다.

## 왜 이 기준인가

이전 방식은 긍정 비율에만 15점을 부여해 유보와 불참이 같고, 긍정 1표와 10표가 같았다. 최대 25%로 바꾸면서 정량을 함께 환산하고 세 입장을 구분한다. 유보 65는 중간값보다 약간 우호적이고, 불참 15는 참여와 확실히 구분한다. 표본이 적을수록 기존 정량점수에 가깝게 유지한다.

경쟁률·확약·유통의 상대 배점과 S/A/B/C 경계는 유지했다. 가격이 높거나 지표가 미발표라는 이유로 기대 점수를 추가하지 않는다. 수집하지 못한 의견을 우호적으로 추정하는 정책도 도입하지 않는다.

Q=67, 정량 79점의 설명용 예:

| 관측 의견 | 감성 비중 | 종합점수 |
| --- | ---: | ---: |
| 무표본 또는 D-1 전 | 0% | 정량 79 |
| 참여 1 | 5% | 80 |
| 참여 5 | 25% | 84 |
| 유보 5 | 25% | 75 |
| 불참 5 | 25% | 63 |
| 참여 3·유보 1·불참 1 | 25% | 78 |

## 검증·운영 결과

계산·날짜 경계·최신 글·실패 채널·미분류 제외 회귀검사는 기존 파이프라인에 포함한다. 콘텐츠344개·보안58개 검사, TypeScript, 변경부 ESLint와 프로덕션 빌드가 통과했다. 자료 정정 후 전체52개 API의 산식·필드 대조,20개 상장 근거,6개 실제 상세와구코드3개308을 로컬 프로덕션 서버에서 확인했다.

최종 분류기로 [진단 원문8개](../research/2026-11-01-sentiment-v3-validation.json)를 새로 조회했으며 참여6·유보1·불참1을 모두 재현했다. 확인된 누락을 고친 선택표본의 회귀 확인이며, 새 시장 표본의 일반 정확도나 예측력 검증은 아니다. 원문 수정 가능성도 남는다.

현재D-1 실제10RSS·2종목을 새로 수집해 각12원문·수집실패0을 확인했다. 바로팜은 불참1표·감성비중5%로 종합32점, 동원파츠는 참여1표가 있지만 정량미완성으로 발표대기다. 원문 수와 의견 표본을 혼동하지 않는다. 운영 배포의 최종 확인 결과는 PROJECT_HISTORY의 이번 작업 기록에 남긴다.

[PR11](https://github.com/GPTcreate/iposcore/pull/11)을 a54b66d로 병합했고 [Vercel 운영 배포](https://vercel.com/iposcore/iposcore/AXVBKA3HNgL8uujTCNrnyntRhSNT)가 성공했다. 2026-11-01 13:03:44UTC에 운영52개 API의 정정값·점수·버전·지수·비중이 전부일치하고,상장20개근거·실제상세6개·구코드3개308·공개산식이정상임을확인했다.

과거 연구의 자동 0표 결과는 당시 규칙의 결과로 보존한다. 수동 참고 라벨을 운영 자동 분류로 복사하지 않는다. 이후 분류기 재조회 결과는 실제 새 수집시각을 사용한다.
