# 밴(계정 정지) 없는 자동 마케팅 및 오가닉 트래픽 성장 전략 가이드
*(Zero-Ban Automated Traffic Playbook for iposcore.kr)*

이 문서는 네이버, 카카오톡, 텔레그램, 구글 등의 스팸 필터 및 커뮤니티 관리자 제재(밴/강퇴)를 100% 회피하면서 지속적인 고품질 방문자(트래픽)를 유입시키는 실전 마케팅 시스템 구축 가이드입니다.

---

## 1. ⚠️ 왜 기존 매크로 프로그램은 100% 밴을 당하는가?

1. **무차별 링크 도배**:
   - 네이버 카페, 뽐뿌, 블로그 댓글에 봇으로 동일한 링크를 반복 등록하면 네이버 스마트봇 AI가 **IP 차단, 네이버 ID 영구정지, 도메인(iposcore.kr) 스팸 블랙리스트 등재** 처분을 내립니다.
2. **도메인 블랙리스트의 치명적 위험**:
   - 도메인 자체가 스팸으로 찍히면 검색엔진 노출이 완전히 차단되어 서비스가 회복 불능 상태에 빠집니다.
3. **해결책**:
   - 봇 매크로가 아닌 **"공식 Bot API"**, **"검색엔진 SEO"**, **"사용자 자발적 공유(인센티브 바이럴)"**, **"스팸 필터 0% 회피 텍스트 생성기"** 4중 구조로 안전하게 전환해야 합니다.

---

## 2. 🛡️ 4대 무정지(Zero-Ban) 자동 마케팅 엔진

### ① 텔레그램 공모주 알림 채널 운영 (가장 효과적, 밴 위험 0%)
- **원리**: 텔레그램 공식 Bot API를 활용하여 전용 채널(예: `@iposcore_channel`)에 매일 청약 D-1 및 청약 당일 아침 브리핑을 자동 전송.
- **효과**: 
  - 주식 투자자들은 텔레그램 알림을 실시간으로 켜놓고 봅니다.
  - 채널 내 글이 주식 단톡방, 지인들에게 자연스럽게 전달(포워딩)되면서 폭발적 바이럴 발생.
- **세팅 방법 (무료 1분)**:
  1. 텔레그램에서 `@BotFather` 검색 ➡️ `/newbot` 입력하여 봇 생성 ➡️ `HTTP API Token` 복사.
  2. 내 텔레그램 채널 생성 ➡️ 봇을 채널 관리자로 추가.
  3. Vercel 환경변수에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 등록하면 끝!

---

### ② 네이버 & 구글 검색엔진 자동 색인 (Programmatic SEO & RSS)
- **원리**: 신규 공모주가 등록되거나 수요예측이 확정될 때마다 검색엔진에 실시간 RSS 피드 제공.
- **주요 피드 주소**:
  - RSS 피드: `https://iposcore.kr/rss.xml`
  - 사이트맵: `https://iposcore.kr/sitemap.xml`
- **효과**:
  - `[종목명] 공모주`, `[종목명] 수요예측`, `[종목명] 공모가` 검색 시 네이버 VIEW탭 및 웹문서 상단 자동 점유.
  - 매일 비용 0원으로 수천 명의 진성 투자자 자동 유입.
- **등록 방법**:
  - **네이버 서치어드바이저** 접속 ➡️ `iposcore.kr` 사이트 등록 ➡️ [요청] ➡️ [RSS 제출]에 `https://iposcore.kr/rss.xml` 입력.
  - **구글 서치 콘솔** 접속 ➡️ [Sitemaps]에 `sitemap.xml` 제출.

---

### ③ 커뮤니티 밴 방지 바이럴 텍스트 1초 복사기 (관리자 기능)
- **위치**: 관리자 제어판(`/admin`) ➡️ [4. 밴 없는 자동 마케팅 & 바이럴 허브]
- **원리**: 
  - 스팸 금지어가 없는 자연스러운 실제 투자자 어조의 질문/정보글을 AI가 실시간 자동 생성.
  - 관리자가 원하는 종목을 선택하고 **[1초 복사]** 버튼을 눌러 주요 커뮤니티(월급쟁이재테크연구실, 뽐뿌 재테크포럼, 주식 오픈채팅방)에 하루 1번 가볍게 공유.
- **특징**:
  - 광고 티가 전혀 나지 않는 순수 정보글이므로 카페 운영자 강퇴 및 밴 위험 0%.
  - 계산기 링크와 상세 분석 링크가 포함되어 유입 전환율 극대화.

---

### ④ 사용자 자발적 공유 (Viral Loop)
- **원리**: 서비스를 이용한 사용자가 자신의 배정 예상 주수나 계산기 결과를 카카오톡, 블로그 등에 직접 공유하도록 유도.
- **장치**:
  - 상세 페이지 상단 `[카카오톡 공유하기]`, `[링크 복사]`
  - 계산기 결과 `[내 배정 결과 단톡방에 공유하기]`
- **효과**: 유저가 유저를 부르는 지속 가능한 바이럴 성장 루프 완성.
