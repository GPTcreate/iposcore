# 핵심 흐름 유지와 콘텐츠 보완

기존 수정의 일괄 종목 숨김과 관리자 비밀번호 변경은 사용자 목적을 넘어섰다. 이번 변경은 일정 목록 → 점수 → 종목 상세 → 계산·실제 리뷰 → 공유·구독 흐름을 유지한다. 초기 데이터 수를 서비스 상한으로 사용하지 않는다.

## 화면과 데이터

- 모든 등록 종목과 상태 탭을 복구했다. 과거 상장·철회 기록도 보존한다. 새 공시 발견은 실제 회사명·접수일·원문으로 카드에 추가하며 모르는 일정·가격·주관사는 생성하지 않는다.
- 금융 지표가 유효하면 등록자료 참고점수를 계산한다. 공시 원문에서 확인한 지표는 확인 상태를 별도로 표시한다. 공모가·희망밴드는 점수 산식에 쓰지 않으므로 계산을 막는 조건에서 뺐다. 미발표 지표에 임의 평균점수는 넣지 않는다.
- 실제 블로그 원문·명시 입장 집계, 무표본null, 중복 제거와 실패 보존을 유지한다. 원문 모음이 공시 확인을 대신하지 않는다.
- 상장 후 가격·수익률·1주 차익, 주관사 배정·수수료, 공모 규모·시총·유통금액, 개선한 손익 계산기를 되살렸다. 출처·산식·자료 주의와 반복 메모는 접어 두었다. 홈의 첫 콘텐츠는 종목 목록이다.
- 기존 관리자 비밀번호를 그대로 사용할 수 있다. 서버에는 호환 해시만 저장하며 설정된 ADMIN_SECRET가 있으면 그 값이 우선한다. 비밀번호를 로그·문서에 남기지 않았다.

## 저장과 자동 갱신

누적48개 중 유효3지표로 계산되는 점수는24개이며 나머지는 발표 대기다. 신규 후보는 세 지표를 각각 수신해야 점수를 계산한다. 미발표 확약률의 기본값0은 실제 공시에서 확인한0%와 구분한다. 일정이 있는 기존 종목을 먼저 표시하고, 신규 공시만 발견한 후보는 뒤에 표시한다. 수집 실패·추출 불가·저장 불가와 배포 완료를 별개 상태로 취급한다.
